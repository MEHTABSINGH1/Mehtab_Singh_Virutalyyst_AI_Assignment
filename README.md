## Overview
This project implements a complete machine learning pipeline to classify handwritten digits (0–9) using **classical machine learning techniques**.  
The focus is on correct preprocessing, model selection, evaluation, and clear reasoning.

---

## Dataset
- MNIST dataset in **CSV format**
- Each row: digit label + 784 pixel values
- Files used:
  - `mnist_train.csv`
  - `mnist_test.csv`

---

## Approach
- Load and explore data
- Normalize pixel values (0–1)
- Optional PCA for dimensionality reduction
- Train and evaluate:
  - KNN
  - SVM
  - Decision Tree
- Analyze misclassified samples
- Implement **KNN from scratch**

---

## Evaluation
- Accuracy
- Confusion matrices
- Misclassification visualization
